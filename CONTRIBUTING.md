# Contributing

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make a focused change and test it.
4. Commit with a clear message.
5. Open a pull request describing the change and why it is useful.

Please be respectful, follow the Code of Conduct, and include enough detail
for maintainers to understand and review your contribution.
