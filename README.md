# Simple Interest Calculator

A beginner-friendly Bash script that calculates simple interest from a principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Requirements

- Bash shell (Linux, macOS, or Windows with Git Bash/WSL)

## Usage

1. Clone or download this repository.
2. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

3. Run it:

   ```bash
   ./simple-interest.sh
   ```

4. Enter the principal, annual rate of interest, and time period when prompted.

## Example

For principal `1000`, rate `5`, and time `2` years, the simple interest is `100`.
